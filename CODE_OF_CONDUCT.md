# Código de conduta

Este é um espaço para quem pesquisa, estuda e cuida de pessoas. Esperamos o mesmo respeito que se
espera numa boa reunião clínica ou num bom grupo de pesquisa:

- Trate todos com respeito, independentemente de formação, nível acadêmico, instituição, gênero, raça,
  orientação, deficiência ou nacionalidade.
- Critique ideias e código, nunca pessoas.
- Valorize quem está começando: dúvida de iniciante é bem-vinda.
- Não publique dados de pacientes nem informações pessoais de terceiros.
- Não use o repositório para promover fraude acadêmica, plágio ou fabricação de resultados.

Comportamentos abusivos podem levar à remoção de comentários, issues ou PRs e ao bloqueio de quem os
publicou. Para relatar algo, abra uma issue ou contate o mantenedor pelo GitHub.
